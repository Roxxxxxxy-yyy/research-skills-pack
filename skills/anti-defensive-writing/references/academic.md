# 学术写作：主张与证据相配

本参考适用于论文、教材、综述、基金申请及审稿回复。既有科研规范和目标期刊要求继续适用；润色本身不构成数据分析或全文文献核验。

## 论证主线

辨认研究问题、核心概念、设计与材料、主要结果、理论解释及适用范围。根据已提供的材料编辑，资料不足时保留具体待核实项。不要为了润色要求用户补齐整套研究档案。

引言把问题和已有解释的不足讲清楚。研究缺口需要具体比较，不能用“鲜有关注”“填补空白”代替证据。常规润色不自动扩展为创新性检索；用户要求新研究构思或创新性评价时按科研规则核验相近研究。

理论段落说明概念关系与推导过程。“理论认为”后面要有可识别的命题和来源。删除多次宣布“这一机制十分重要”的评价，保留解释机制所需的推理。

摘要呈现问题、方法、核心发现和贡献，保留影响解释的设计及范围。期刊要求结构式摘要时照其格式，不把规范结构误判为模板化问题。

贡献具体回答：研究改变了已有解释的哪一点、提供了什么证据或澄清了什么条件。比较对象和新颖性没有核验时，不写首次、突破、领先、全面或独创。

## 结论强度

| 已有材料 | 编辑要求 |
| --- | --- |
| 观察到统计关联 | 表述关联；不升级为促进、导致或通过某机制产生影响 |
| 随机实验或因果识别设计 | 在已支持的识别条件和结果范围内表述，不能仅因出现“实验”就断言机制成立 |
| 中介分析 | 区分统计间接效应与被识别的因果机制，沿用已核验的结论强度 |
| 不显著结果 | 保留未达阈值的事实和现有估计，不能写成没有效应，也不能美化成支持假设 |
| 支持等效性或非劣效性的结果 | 仅在有对应设计和检验依据时作此结论 |
| 访谈、案例或质性解释 | 保留情境与材料依据，不补造普遍性、发生率或因果识别 |
| 理论命题、计划、探索发现 | 保持其身份，不能改成已证实的规律或验证性结果 |

保留提供的效应量、置信区间、p 值和重要不显著比较。用户材料缺少必要统计量时可以指出缺项，不凭措辞补算或编造。重复测量、聚类或非独立样本的设计信息不能因压缩文字丢失。

## 局限与不利结果

局限应明确其影响：某个设计条件限制了什么推断，哪个替代解释尚未排除，哪种外推还需检验。删除“本研究仍存在一些不足”后若没有损失信息，可直接进入具体内容。

正面界定研究范围不能替代必要的推断警示。例如交代“对两家企业进行调查”并不能自动传达“不能识别方向”，后者影响解释时要明确保留。

不利结果按原有评价标准与有利结果一同报告。可以客观说明取舍，不能换指标、编机制、弱化失败或把探索分析包装成预注册结果。

局限放在读者需要的位置。摘要中的关联结论应直接用关联措辞，不能先写因果断言再指望讨论部分补救。

## 引用与证据边界

引用贴近所支持的命题，改动论点后检查引用是否仍然对应。保留未读原文、仅摘要、二手转引及待核实的真实状态；不把来源不明的断言改成权威事实。需要检索时按现有科研规则核对书目信息，不上传未公开数据或材料。

语言修改和证据修正分开记录。具体引用有疑点时定位该项，不给整篇文章追加泛泛的免责声明。

## 审稿回复

先直接回答审稿人实际提出的问题，再说明改了什么、根据什么、改在何处。礼貌致谢简短即可；已确认的错误应明确承认并纠正。不同意时提出证据或方法理由，不编造已补做的实验、页码或分析。

不要把所有潜在质疑都抄进论文的局限。真实影响解释的疑点应保留，纯粹可选的扩展研究可以说明其价值和范围。
