# Active research — Codex

用当前可用的 Codex 网络检索、网页阅读和文件工具开展研究。上游 Actionbook、agent-browser、json-ui 和父仓库代理为可选生态，本安装不依赖这些工具；不运行不存在的工具、绕过访问控制或注入认证信息。

1. 从用户请求提炼范围、核心问题、时间窗口和交付形式。先分解问题与检索策略，随后持续推进，已有信息足够时不重复追问。
2. 从原始论文、官方文件、数据和可靠机构进行多来源检索，追踪关键论断的最初出处。技术事实优先一手资料，比较相互独立的来源。
3. 保存来源、发布日期、检索日期、支持的论点和局限。区分已核实事实、来源判断与自己的推断；对矛盾证据解释差异，不用来源数量替代质量。
4. 根据证据回答问题并给出可执行结论。不要编造全文阅读、付费数据库访问、数据或引用；访问失败时换公开来源并披露对结论有影响的缺口。
5. 按用户要求生成报告。Markdown 可直接交付；HTML 使用自包含标准 HTML/CSS；Word 和 PDF 调用可用的 documents、pdf 技能并核验版式。不安装上游单体仓库的渲染工具以完成普通报告。

上游研究流程保留于 [references/upstream-SKILL.md](references/upstream-SKILL.md)。其中强制专用浏览器、固定轮数、工具排除以及原平台代理配置不适用于本 Codex 入口。研究输出保存在当前项目。
